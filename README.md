# BLOOM — Personal OSINT

**BLOOM** — консольный OSINT-инструмент для структурированного анализа данных из открытых и разрешённых источников.

Проект объединяет несколько инструментов в одном интерфейсе и может использовать AI-модель для анализа результатов.

> ⚠️ Используйте BLOOM только для собственных данных, тестовых целей или при наличии разрешения на исследование.

---

## Возможности

### 🤖 AI-анализ

BLOOM может использовать совместимый с OpenAI API интерфейс для:

* классификации цели;
* составления плана исследования;
* выбора подходящих инструментов;
* анализа результатов;
* кросс-проверки информации;
* формирования итогового отчёта.

Поддерживается ввод собственного API-ключа и модели при запуске программы.

---

### 🔎 Search API

Поддерживается подключение внешнего Search API.

Пользователь самостоятельно указывает:

* API-ключ;
* URL API;
* параметры поиска.

Ключи и URL не хранятся непосредственно в исходном коде проекта.

---

### 🌐 DNS Lookup

Получение публичных DNS-записей домена:

* `A`
* `AAAA`
* `MX`
* `NS`
* `TXT`

Пример:

```text
example.com
```

---

### 🌍 IP Lookup

Получение IP-адресов, связанных с доменным именем.

Выводит:

* hostname;
* aliases;
* IPv4-адреса.

---

### 📋 RDAP

Получение публичной регистрационной информации о домене через RDAP.

Может отображать:

* доменное имя;
* handle;
* статус;
* события регистрации;
* nameservers.

---

### 👤 Sherlock

Проверка username по публичным сайтам с использованием Sherlock.

Пример:

```text
username
```

Результат Sherlock следует рассматривать как список кандидатов, а не как доказательство принадлежности аккаунта конкретному человеку.

---

### 🔍 Google Dork Generator

Автоматическая генерация поисковых запросов для публичного поиска.

Например:

```text
"example"
"example" filetype:pdf
"example" filetype:docx
"example" after:2025/01/01
```

---

### 🧩 Google Dork Parser

Разбор существующего Google Dork на отдельные компоненты.

Поддерживаются:

* `site:`
* `filetype:`
* `after:`
* `before:`
* исключения через `-`
* фразы в кавычках.

Также формируется URL для ручного поиска.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/BLOOM.git
cd BLOOM
```

Замените `YOUR_USERNAME/BLOOM` на адрес вашего репозитория.

---

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Если `requirements.txt` ещё не создан, установите зависимости:

```bash
pip install requests dnspython pystyle colorama openai
```

Для Sherlock:

```bash
pip install sherlock-project
```

---

## Запуск

```bash
python main.py
```

При запуске программа попросит указать конфигурацию:

```text
============================================================
                  BLOOM API CONFIG
============================================================

Введите API нейросети:
Введите модель нейросети [Enter = ...]:
Введите API для поиска:
Введите URL API для поиска:
```

API-ключи вводятся локально пользователем и не должны добавляться в Git.

---

## Безопасность API-ключей

**Никогда не добавляйте реальные API-ключи в исходный код.**

Нельзя делать:

```python
API_KEY = "your-real-api-key"
```

Используйте интерактивный ввод или переменные окружения.

Перед публикацией проекта убедитесь, что в репозитории отсутствуют:

```text
API keys
Tokens
Passwords
Private keys
Cookies
Session files
.env
```

Рекомендуемый `.gitignore`:

```gitignore
.env
.env.*
venv/
.venv/
__pycache__/
*.pyc
*.pyo
*.log
```

## Пример использования

После запуска:

```text
1. OSINT анализ
2. DNS lookup
3. IP lookup
4. RDAP lookup
5. Sherlock
6. Google Dork generator
7. Google Dork parser
0. Выход
```

Например, для DNS:

```text
Выберите пункт: 2

Домен: example.com
```

Программа получит доступные публичные DNS-записи.
