# AURORA — Personal OSINT

**AURORA** — консольный OSINT-инструмент для структурированного анализа данных из открытых и разрешённых источников.

Проект объединяет несколько инструментов в одном интерфейсе и может использовать AI-модель для анализа результатов.

> ⚠️ Используйте AURORA только для собственных данных, тестовых целей или при наличии разрешения на исследование.

---

## Возможности

### 🤖 AI-анализ

AURORA может использовать совместимый с OpenAI API интерфейс для:

* классификации цели;
* составления плана исследования;
* выбора подходящих инструментов;
* анализа результатов;
* кросс-проверки информации;
* формирования итогового отчёта.

Поддерживается ввод собственного API-ключа и модели при запуске.

---

### 🔎 Search API

Поддерживается подключение внешнего Search API.

Пользователь самостоятельно указывает:

* API-ключ;
* URL API;
* параметры поиска.

Ключи и URL не хранятся непосредственно в исходном коде проекта.

---

### 🌐 DNS Lookup

Получение публичных DNS-записей домена:

* `A`
* `AAAA`
* `MX`
* `NS`
* `TXT`

---

### 🌍 IP Lookup

Получение IP-адресов, связанных с доменным именем.

Выводит:

* hostname;
* aliases;
* IPv4-адреса.

---

### 📋 RDAP

Получение публичной регистрационной информации о домене через RDAP.

Может отображать:

* доменное имя;
* handle;
* статус;
* события регистрации;
* nameservers.

---

### 👤 Sherlock

Проверка username по публичным сайтам с использованием Sherlock.

Результат Sherlock следует рассматривать как список кандидатов, а не как доказательство принадлежности аккаунта конкретному человеку.

---

### 🔍 Google Dork Generator

Генерация поисковых запросов для публичного поиска.

Пример:

```text
"example"
"example" filetype:pdf
"example" filetype:docx
"example" after:2025/01/01
```

---

### 🧩 Google Dork Parser

Разбор существующего Google Dork на отдельные компоненты.

Поддерживаются:

* `site:`
* `filetype:`
* `after:`
* `before:`
* исключения через `-`;
* фразы в кавычках.

Также формируется URL для ручного поиска.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/AURORA.git
cd AURORA
```

---

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Если `requirements.txt` ещё не создан:

```bash
pip install requests dnspython pystyle colorama openai
```

Для Sherlock:

```bash
pip install sherlock-project
```

---

## Запуск

```bash
python main.py
```

При запуске AURORA попросит указать конфигурацию:

```text
============================================================
                  AURORA API CONFIG
============================================================

Введите API нейросети:
Введите модель нейросети [Enter = default]:
Введите API для поиска:
Введите URL API для поиска:
```

API-ключи вводятся локально пользователем и не должны добавляться в Git.

## Безопасность API-ключей

**Никогда не добавляйте реальные API-ключи в исходный код.**

Плохо:

```python
API_KEY = "your-real-api-key"
```

Хорошо:

```text
Введите API нейросети:
```

Рекомендуемый `.gitignore`:

```gitignore
.env
.env.*
venv/
.venv/
__pycache__/
*.pyc
*.pyo
*.log
```

Перед публикацией убедитесь, что репозиторий не содержит:

```text
API keys
Tokens
Passwords
Private keys
Cookies
Session files
.env
```
